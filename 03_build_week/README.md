# Week 3 — Workspace

This folder is where you build the deliverables for **Week 3: Build the
Meeting Notes → Summary → Human Review Engine**.

📖 Full lesson, day-by-day objectives, script specs, and the project
completion checklist live in:
**[`../../fundamentals/03_build_week/README.md`](../../fundamentals/03_build_week/README.md)**

## Deliverables for this folder
- `engine_v1.py` — Day 15-16 (run loop, no pauses)
- `engine_v2.py` — Day 17-18 (adds `--resume`)
- `engine_v3.py` — Day 19-20 (hardened, audit log, `--verify`)
- `ENGINE_README.md` — Day 21 (what the engine does, how to run it,
  workspace file structure)
- `transcript.txt` — Day 21 (terminal session: escalate → pending →
  resume → success)
- `what_i_learned.md` — Day 21 (project-level retro, separate from weekly notes)
- `config/schema.json`, `config/system_prompt.txt` — moved here from
  Week 2 on Day 15-16 (already provided, stubbed identically to Week 2's)

## About the `workspace/` subfolder
`engine_v1/v2/v3.py` read `workspace/input.txt` and write
`model_output.json`, `final_summary.json`, `PENDING_meeting_summary.md`,
`AUDIT_LOG.md`, etc. into the `workspace/` folder inside this directory.
That folder already exists here (empty, with a `.gitkeep`) and is
**gitignored** — its contents are generated by running the engine, not
hand-written.

Each `engine_vX.py` should be a copy-forward-and-extend of the previous
one (per the spec) — don't start `engine_v2.py` from scratch.

Commit each script when it's done — see the root
[`README.md`](../../README.md) for commit message conventions.
