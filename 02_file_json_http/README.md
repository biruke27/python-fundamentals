## About the `workspace/` subfolder
`workspace_manager.py` (and later `model_caller.py`) create and use a
**runtime** `workspace/` folder inside this directory — for `input.txt`,
`run_log.txt`, `model_output.json`, `raw_response.txt`, etc. That folder
already exists here (empty, with a `.gitkeep`) and is **gitignored** —
its contents are generated by running your scripts, not hand-written, so
they aren't committed.

Commit each script when it's done — see the root
[`README.md`](../../README.md) for commit message conventions.
