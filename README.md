# Python Fundamentals — Workspace

This is my working repo for a 3-week, learn-by-doing Python track. Each
folder corresponds to one week and contains the scripts, configs, and
notes I'm building as deliverables.

## Structure

- **`01_core_python/`** — Week 1: variables, loops, lists, dicts,
  functions, error handling
  - `classify_notes.py`, `build_agenda.py`, `summary_stats.py`,
    `validation_helpers.py`
  - `what_i_learned.md` — daily notes

- **`02_file_json_http/`** — Week 2: file I/O, JSON, and talking to a
  local LLM (Ollama)
  - `workspace_manager.py`, `schema_checker.py`, `model_caller.py`
  - `schema.json`, `system_prompt.txt`, `test_input.txt`
  - `workspace/` — runtime output (gitignored)
  - `what_i_learned.md`

- **`03_build_week/`** — Week 3: the Meeting Notes → Summary → Human
  Review engine
  - `engine_v1.py` → `engine_v2.py` (`--resume`) → `engine_v3.py`
    (hardened, audit log, `--verify`)
  - `config/` — schema + system prompt used by the engine
  - `workspace/` — runtime output (gitignored)
  - `ENGINE_README.md`, `transcript.txt`, `what_i_learned.md`

## Workflow

Each script started as a stub (docstring spec + `# TODO`s) and gets
filled in day by day. Commits are made per script/day, e.g.:
Day 1-2: classify_notes.py
Day 8-9: workspace_manager.py
Day 15-16: engine_v1.py
`*/workspace/*` folders hold files generated by running the scripts
(logs, model output, pending review files, audit log) — gitignored since
they're regenerated each run, not hand-written.
